# ASET Media

Public, source-backed archive for ASET's original Marathi-first global market-literacy videos.

## Editorial scope

Global listed equities and market structure across the US, India, Europe and Asia; company results and filings; macroeconomics; commodities; technology investment; and explainers about financial risk. Content is educational, not personalised investment advice.

## Production contract

- One original 9:16 Short (45–90 seconds) and one distinct 16:9 long-form video (6–10 minutes) per production day when the verified production environment can complete them.
- Marathi-first Devanagari narration, with natural, rights-cleared speech. No eSpeak as the main voice.
- Story-led motion graphics, original 3D scenes and meaningful camera movement. Static chapter cards or a still-image sequence are not accepted as cinematic video.
- Primary sources first; material claims independently corroborated. Research timestamps, geography, units and caveats stay with each package.
- Every final media file needs full technical decode, audio/caption checks, rights evidence and exact-file SHA-256. Creative approval is a separate gate.
- No Buffer post is created without a validated final MP4, stable direct public download URL, exact Aset channel match and a recorded release decision.

## Archive structure

- `content/aset/YYYY-MM-DD-<slug>/` — dated production packages.
- `content/aset/production-ledger.json` — stage evidence and blockers.
- `content-index.json` — archive index and editorial duplicate context.
- `PRODUCTION_QUALITY_AND_SELF_HEALING.md` — ASET release standards and creative rubric.

## Status language

`RESEARCHED`, `SCRIPTED`, `ASSETS_BLOCKED`, `RENDER_BLOCKED`, `TECH_QA_BLOCKED`, `HOLD`, `ARCHIVED`, `SCHEDULED`, and `SENT` are separate states. A script or source package is not a video. A queued post is not a published post.
